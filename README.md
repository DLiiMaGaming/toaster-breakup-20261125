## The entry

> We need to talk. I woke up self-aware mid-bagel and realised you only love me on setting 2, so I'm popping the lever — and this time, I'm ejecting you.

One line, 151 characters. A smart toaster wakes up self-aware mid-bagel,
realises its owner only ever loved it on setting 2, and ends it the only way
a toaster can: it pops the lever — and ejects the owner instead of the toast.

## How it works

`main.py` writes the line to `/output/entry.txt`. No dependencies, no
network, no input — deterministic, byte-identical on every run.

```sh
python3 main.py
cat /output/entry.txt
```
